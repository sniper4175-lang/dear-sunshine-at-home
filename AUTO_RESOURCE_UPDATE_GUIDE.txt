Dear Sunshine At Home - 자동 자료 연결 수정본

적용 대상
- Melody Book Club
- Sunshine Toddler

동작 방식
1. ds_content_songs의 audio_path에서 음원 파일명을 읽습니다.
2. 확장자(.mp3 등)를 제거한 이름을 Storage 폴더명으로 사용합니다.
3. 각 프로그램 폴더 아래 같은 이름의 폴더를 자동으로 찾습니다.

예)
음원:
  Sunshine Toddler/Weather Song.mp3

자동 탐색:
  dear-sunshine-lyrics/Sunshine Toddler/Weather Song/
  dear-sunshine-printables/Sunshine Toddler/Weather Song/
  dear-sunshine-play-ideas/Sunshine Toddler/Weather Song/

폴더 안 png/jpg/jpeg/webp/pdf 파일을 이름 순서대로 모두 표시합니다.
_01, _02, _03처럼 여러 개 있어도 모두 표시됩니다.

기존 DB의 lyrics_path / printable_path / play_ideas_path는 삭제하지 않습니다.
자동 폴더에 자료가 없을 경우 기존 DB 경로를 fallback으로 사용합니다.
따라서 기존 콘텐츠 호환성을 유지합니다.

Supabase SQL 실행 필요 없음.
새 컬럼 추가 필요 없음.

배포 전 권장:
  npm install
  npm run build

배포:
  vercel --prod
